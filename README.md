# 广告数据库网站交接包 · 2026-10-15

这是目前能找到的最新运行代码及可用开发资料，供同事运行、维护和继续恢复源码。

**当前线上版本完整的 React/TypeScript 原始源码尚未找回。** 本包包含两套明确分开的代码：`runtime` 是当前版本，`recovered-source` 是可构建的历史源码。历史源码不能直接覆盖当前线上服务。

网站：https://tiktok-data.sligenai.cn/tiktok-ad-assistant

## 同事从这里开始

1. 解压整个 ZIP，安装 Node.js 24（含 npm）。
2. 在解压后的根目录执行：

```bash
node tools/verify.mjs
```

这会按锁文件安装三个项目的依赖，构建历史源码，再用独立临时数据库分别检查当前版与历史版。首次安装需要访问 npm registry。不会连接真实生产数据库，也不会操作真实广告。

3. 验证通过后启动当前版演示：

```bash
node tools/demo.mjs
```

打开终端打印的 `DEMO_URL`，看到两条演示广告即可查看当前界面；按 Ctrl+C 退出。无真实视频素材，演示不调用 OSS、AI 或采集服务。
